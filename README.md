# h-ngagubbe
Ett hängagubbe-spel där man ska gissa bokstäver och lyckas hitta ordet innan gissningarna tar slut.

Vecka 45 började vi med det här programet, jag(Magnus) och Vide.W kodade första delen av vår kod denna lektion. 

Nu, Vecka 46 fortsatte vi men hänga-gubbe spelet. Jag (Magnus), Elliot, och Vide.W jobbade på det och lade till några funktioner. Några av dessa är: Två variabler som räknar de bokstäverna som var fel respektive rätt. Och en print-sats som skriver ut ordet med stjärnor och de bokstäver som man har gissat rätt. Dessutom en printsats som skriver ut felgissningarna.
